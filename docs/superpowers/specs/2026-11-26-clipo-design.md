# Cross-Platform Clipboard History & Snippet Manager — Design Specification

> **Status:** Approved
> **Inspiration:** [Maccy](https://maccy.app) (MIT, macOS)
> **App / Project Name:** `Clipo`

---

## 1. Intent & Why

Build a fast, lightweight, open-source (**MIT**) **Clipboard History & Snippet Manager** for **macOS, Windows, and Linux**.

Maccy sets the benchmark for daily clipboard speed on macOS—tiny footprint, instant popup, keyboard-first search and paste, pinning, rich settings, and strict local privacy—but it is macOS-only and limited to flat pinned items. This project does **not** aim to compete with Maccy on macOS; instead, Maccy is the inspiration for bringing that same zero-friction experience (with equal or better optimization, developer-oriented previews, and organized snippets) to developers and everyday users across all three desktop platforms.

---

## 2. Goals, Non-Goals, and Anti-Goals

### Goals
1. **Maccy-grade speed & feel:** Global hotkey or tray/menu-bar click opens the popup in **<50ms** using a pre-warmed hidden window, with instant as-you-type filtering.
2. **Full Maccy core parity:**
   - System tray / menu-bar icon with click-to-open and modifier-click pause/ignore-next shortcuts.
   - Captures text (plain + rich formatting), images, and files with deduplication, copy counts, timestamps, and source-app metadata.
   - Pinning (`Top` or `Bottom`), quick-pick shortcuts (`⌘1–⌘9` / `Ctrl+1–Ctrl+9`), direct auto-paste, and paste-without-formatting.
   - All 5 Maccy Settings domains (**General, Storage, Appearance, Ignore, Advanced**) adapted cleanly cross-platform.
3. **Popup-based Snippet Manager:** Reusable text/code snippets organized with tags/folders, searchable directly inside the popup, with lightweight template variables (`{{date}}`, `{{time}}`, `{{datetime}}`, `{{uuid}}`, `{{clipboard}}`, `{{cursor}}`) and JSON import/export.
4. **Developer-friendly enhancements:** Syntax-highlighted code preview, JSON pretty-print toggle, inline hex/RGB color swatches, image dimensions/file sizes, regex ignore rules, and a cross-platform CLI hook to pause/resume capture from scripts.
5. **Privacy by default:** 100% local storage, automatic respect for password-manager privacy flags, per-app / pasteboard-type / regex ignore lists, and optional clear-on-quit.

### Non-Goals (v1)
- **No cloud sync, accounts, or telemetry.**
- **No global keystroke-logging text expansion** (e.g., typing `;sig` anywhere to auto-replace). Global keystroke hooks introduce heavy OS accessibility permission friction on macOS and break frequently on Linux Wayland.
- **No global per-snippet OS-wide hotkeys** (per-pin/snippet shortcuts operate **in-popup only**).
- **No plugin ecosystem or third-party scripting runtime in v1.**

### Anti-Goals
- **Electron-style resource bloat** (>150MB idle RAM, sluggish window creation).
- **Heavy multi-pane knowledge-base UI** that forces mouse clicks or slows down quick recall.
- **Siloing snippets in a separate slow window** instead of the unified instant popup.

---

## 3. Constraints

- **Target Platforms:**
  - **macOS** (Apple Silicon & Intel, macOS 13+)
  - **Windows** (Windows 10/11 x64 & ARM64)
  - **Linux** (X11 full support; Wayland supported with explicit capability detection and graceful fallback where compositors restrict global shortcuts, cursor coordinates, or synthetic input)
- **Text & Locale Support:** Full UTF-8, IME composition in search, and complex script shaping (e.g., Bengali, Arabic, CJK, emoji).
- **Security & Privacy:** Must detect and skip concealed/transient clipboard entries from password managers (`org.nspasteboard.TransientType`, `org.nspasteboard.ConcealedType`, `org.nspasteboard.AutoGeneratedType` on macOS; `ExcludeClipboardContentFromMonitorProcessing` and `CanIncludeInClipboardHistory` on Windows; `x-kde-passwordManagerHint` on Linux).
- **License:** MIT License.

## 4. Approaches Considered & Selected Stack

### Considered Alternatives
1. **Tauri v2 (Rust backend + Svelte 5 + TypeScript + SQLite)** — *Selected*
2. **Pure Rust Stack (Rust backend + GPUI / Slint / iced)** — Lowest RAM (~15–30MB), but complex script shaping, IME search input, rich multi-tab settings, and contributor velocity are significantly harder.
3. **Shared Rust Core + 3 Native UIs (AppKit + WinUI 3 + GTK4)** — Best native RAM (~25–35MB), but requires 3× UI maintenance across every feature and settings tab.
*(Electron was rejected upfront due to high idle RAM and bundle size.)*

### Selected Architecture Rationale
**Tauri v2 + Rust + Svelte 5 + SQLite** puts every latency-sensitive and OS-level responsibility (clipboard watching, pasteboard filtering, SQLite/blob storage, fuzzy/regex search, tray, hotkeys, window positioning, auto-paste) in native **Rust**, while using a **pre-warmed WebView** with Svelte 5 (compiled, no virtual DOM) for crisp rendering, full international text/IME support, syntax highlighting, and a single cross-platform UI codebase.

## 5. System Architecture

### 5.1 Process & Window Model
One lightweight background Tauri application manages:
1. **Popup Window (`popup`):**
   - Created at app startup in a **hidden, pre-warmed state** (`decorations: false`, `transparent: true`, `always_on_top: true`, `skip_taskbar: true`, `visible: false`).
   - **Open flow (<50ms target):**
     1. Record the currently focused foreground app (`previous_app`) **before** showing the popup.
     2. Query the matching/initial items in Rust.
     3. Compute popup coordinates based on `Appearance -> Popup at` (`Cursor`, `Menu icon`, `Screen center`, `Active window`) clamped to the active monitor's work area.
     4. Position window -> emit snapshot payload to Svelte -> `show()` + `set_focus()`.
   - **Close flow:** On `Escape`, window blur (`focus lost`), or item selection: `hide()` immediately without destroying WebView state; reset search query and return filter tab to `All`.
   - **Preview Pane `[Our Call]`:** Rather than spawning a second floating OS window (which causes focus-stealing and Z-order bugs on Windows and Linux Wayland), the Preview Pane renders as an **attached side panel** inside the popup frame (expanding right or left depending on available screen space). Opens automatically after `Preview delay` ms (default `1500ms`) or immediately on `^Space` / `Ctrl+Space`.
2. **Management Window (`settings`):**
   - Created **lazily** only when the user opens `Preferences...` or `Manage Snippets...`, and destroyed on close to keep idle RAM low.
   - Hosts the 5 Maccy Settings tabs (**General, Storage, Appearance, Ignore, Advanced**) plus a **Snippets** manager tab.

### 5.2 Rust Backend Modules (`src-tauri/src/`)
- **`clipboard/` (Platform Abstraction):**
  - **macOS:** `NSPasteboard` `changeCount` watcher (configurable poll interval, default `250ms`), reading `public.utf8-plain-text`, `public.rtf`, `public.html`, `public.png`/`public.tiff`, `public.file-url`, active frontmost app name/bundle ID, and privacy pasteboard markers.
  - **Windows:** Hidden message-only window (`HWND_MESSAGE`) subscribed via `AddClipboardFormatListener` (event-driven, zero polling), reading `CF_UNICODETEXT`, `CF_DIB`/`PNG`, `CF_HDROP`, `HTML Format`, `Rich Text Format`, foreground window executable/app name, and Windows clipboard history exclusion formats.
  - **Linux:** X11 (`x11rb` XFixes `SelectionNotify` event-driven) and Wayland (`wlr-data-control` / `ext-data-control` via `wl-clipboard-rs` when supported, with a clear status banner in Settings if the compositor restricts background clipboard access).
  - **Self-Write Suppression:** Every clipboard write initiated by our app sets an in-memory content hash + short suppression window (and platform transient/custom marker where supported) so the watcher ignores our own paste writes.
  - **Multi-Format Classification & Dedup `[Our Call]`:**
    - When a copy includes both `plain_text` and rich payloads (`RTF`/`HTML`), **store both** (large rich payloads >64KB go to `blobs/`) so normal paste restores full formatting and `Paste without formatting` emits `plain_text` only.
    - Text deduplication hashes canonical `plain_text`; duplicate copies update `last_copied_at`, increment `copy_count`, and refresh the stored rich payload to the latest copy.
    - When a clipboard write contains both image and text (e.g., spreadsheet selection or browser image copy): classify as `image` if an image format is present without standalone multi-word text (or HTML `<img>` wrapper only), otherwise `text`—while still keeping `thumb_path`/`rich_formats` metadata if present.
- **`paste/` (Focus & Synthetic Paste):**
  - On **Copy only:** write selected item to clipboard, hide popup.
  - On **Copy & Paste:** write selected item (or `plain_text` only when clearing formatting) -> hide popup -> restore focus to `previous_app` -> short yield (`~30–50ms`) -> synthesize `Cmd+V` (macOS `CGEvent`), `Ctrl+V` (Windows `SendInput`), or `Ctrl+V` (Linux X11 `XTest`/uinput; on restricted Wayland, fall back gracefully to Copy-only + subtle notice).
  - On macOS, check `AXIsProcessTrusted()` before auto-pasting; if Accessibility permission is missing, prompt once cleanly and fall back to Copy-only until granted.
- **`storage/` (SQLite + Content-Addressed Blobs):**
  - SQLite in WAL mode (`rusqlite`) stored in OS app-data directory.
  - Large payloads (images, thumbnails, text/rich payloads >64KB) stored as content-addressed files under `blobs/` (SHA-256 filename) so SQLite stays compact and fast.
  - Pre-generated PNG/WebP thumbnails sized for crisp HiDPI display (`image_height * 2px`) served via Tauri's local custom protocol (`clipoimg://`) so scrolling 200+ images stays smooth without base64 bloat over IPC.
- **`search/`:**
  - Supports all 4 search modes from Maccy: **Fuzzy** (`nucleo`), **Exact** (case-insensitive substring), **Regular expressions** (`regex`, invalid syntax handled gracefully), and **Mixed** (exact prioritized, fuzzy fallback).
  - Returns match ranges so Svelte highlights matched characters (`Bold`, `Underline`, or `Highlight`).
- **`snippets/`:**
  - Template resolver supporting `{{date}}` (`YYYY-MM-DD` or `{{date:FORMAT}}`), `{{time}}`, `{{datetime}}`, `{{uuid}}`, `{{clipboard}}`, and `{{cursor}}` (strips marker; if auto-pasting, optionally moves caret back `N` characters via synthetic left-arrow keys, gated as a toggleable best-effort setting).
  - JSON import/export for sharing or backing up snippet libraries.
- **`ipc/` & Local CLI Control:**
  - Cross-platform local IPC socket/named pipe + CLI flags on the binary (`clipo --pause`, `--resume`, `--ignore-next`, `--toggle`) replacing Maccy's macOS-only `defaults write` workflow.
- **`updater/` `[Our Call]`:**
  - `Check for updates automatically` (toggleable in `General`, matching Maccy) uses `tauri-plugin-updater` against signed GitHub Releases manifests for `.dmg`/`.app`, `.msi`/`.exe`, and `.AppImage`, and falls back to a notify-only release link for distro-managed Linux packages (`.deb`/`.rpm`). Zero analytics or telemetry headers.

## 6. Data Schema (SQLite)

### `history_items`
| Column | Type | Notes |
|---|---|---|
| `id` | INTEGER PK | |
| `kind` | TEXT | `'text' \| 'image' \| 'file'` |
| `content_hash` | TEXT UNIQUE | SHA-256 of canonical payload (`plain_text`, image bytes, or sorted file paths) |
| `title_preview` | TEXT | First ~300 chars (single-line normalized for list display) |
| `full_text` | TEXT NULL | Inline text up to 64KB; NULL if stored in `blob_path` |
| `plain_text` | TEXT NULL | Plain-text payload for `Paste without formatting` and search |
| `rtf_payload` / `html_payload` | TEXT NULL | Inline rich formatting up to 64KB (or `rich_blob_path` when larger) |
| `rich_blob_path` | TEXT NULL | Relative path under `blobs/` for large RTF/HTML payloads |
| `blob_path` | TEXT NULL | Relative path under `blobs/` for images or >64KB text |
| `thumb_path` | TEXT NULL | Pre-generated thumbnail path for images |
| `image_width` / `image_height` | INTEGER NULL | Pixel dimensions |
| `byte_size` | INTEGER | Total payload + blob size for storage stats |
| `source_app_name` | TEXT NULL | Display name (e.g. `Notion`) |
| `source_app_id` | TEXT NULL | Bundle ID / executable name / WM_CLASS |
| `first_copied_at` | INTEGER | Unix ms |
| `last_copied_at` | INTEGER | Unix ms |
| `copy_count` | INTEGER | Default `1`, incremented on duplicate copy |
| `is_pinned` | INTEGER | `0` or `1` |
| `pin_shortcut` | TEXT NULL | Optional **in-popup** quick-pick key |
| `pinned_at` | INTEGER NULL | Ordering within pinned section |

### `snippets`
| Column | Type | Notes |
|---|---|---|
| `id` | INTEGER PK | |
| `title` | TEXT | Searchable snippet name (e.g., `Git new branch`) |
| `content` | TEXT | Body (may contain `{{variables}}`) |
| `tags_json` | TEXT | JSON array of tags/folder labels (e.g., `["git"]`) |
| `language` | TEXT NULL | Optional syntax language (`bash`, `sql`, `json`, `auto`) |
| `shortcut_key` | TEXT NULL | Optional **in-popup** quick-pick key |
| `is_pinned` | INTEGER | `0` or `1` (`[Our Call]` pins favorite snippets to top of `Snippets` tab) |
| `use_count` | INTEGER | Usage counter |
| `created_at` / `updated_at` | INTEGER | Unix ms |

### `ignore_rules`
| Column | Type | Notes |
|---|---|---|
| `id` | INTEGER PK | |
| `rule_type` | TEXT | `'app' \| 'pasteboard_type' \| 'regex'` |
| `pattern` | TEXT | App ID/name, MIME/UTI/clipboard format, or regex |
| `enabled` | INTEGER | `1` or `0` |

### Retention Rules
- Unpinned history items exceeding `storage.max_items` (default `200`) are pruned oldest-first according to `Sort by`, deleting unreferenced blob files.
- **Pinned items and snippets are never auto-pruned.**
- `Clear all` deletes all unpinned `history_items` (and unreferenced blobs); pinned items and snippets remain intact.

## 7. Detailed UI & Feature Behavior

### 7.1 Popup Layout, Search Visibility & Shortcut Mapping
- **Header:** Optional title + search input (`Show search field`: `Always` / `When typing` / `Never`). Typing anywhere immediately filters without clicking the input.
- **Filter Strip (compact):** `All` | `Snippets` | `Images` | `Files` (switchable via `Tab` / `Shift+Tab` or click; always resets to `All` on popup open).
- **Default `All` Tab Behavior (User-Confirmed):**
  - **When search is empty:** Displays **Pinned history items + Recent History** only (exact Maccy cleanliness; Snippets stay tucked away until searched or opened via the `Snippets` tab).
  - **When typing a search query in `All`:** Shows matching **Pinned items**, matching **Snippets** (badged `[Snippet]` with tags, grouped cleanly right above unpinned history), and matching **Recent History**.
- **`⌘1–⌘9` / `Ctrl+1–Ctrl+9` & Per-Item Shortcuts (User-Confirmed):**
  - `⌘1–⌘9` (or `Ctrl+1–Ctrl+9` on Windows/Linux) always index the **first 9 unpinned history items** currently displayed (matching Maccy's exact numbering, regardless of `Pin to: Top` or `Bottom`).
  - Pinned items and Snippets use **in-popup** `pin_shortcut` / `shortcut_key` bindings (e.g. auto-assigned or user-set modifier+key while popup is open), or arrow keys + `Enter`. No global per-snippet OS hotkeys.
- **Row Visuals:**
  - Optional source app icon, special visible symbols (`↵`, `⇥`, `·`), inline **hex/RGB color swatch**, inline image thumbnail (`Image height` configurable, default `40px`), match highlighting, and shortcut badge.
- **Selection Actions (Configurable in General Settings):**
  - Default `Enter` / click: Copy & Paste automatically (if enabled), or Copy only.
  - Modifier overrides: `⌥` (`Alt`) = Copy only; `⌘` (`Ctrl` on Win/Linux) = Copy & Paste; `⇧⌘` (`Ctrl+Shift`) = Copy, strip formatting, & Paste.
  - `⌥P` / `Alt+P`: Pin / Unpin history item (or favorite-pin in `Snippets` tab).
  - `⌥S` / `Alt+S`: Save current history item as a reusable Snippet.
  - `⌥⌫` / `Alt+Backspace`: Delete item.
  - `^Space` / `Ctrl+Space`: Toggle Preview Pane immediately.
- **Footer (toggleable):** `Clear all` (`⌥⇧⌫`), `New Snippet...`, `Preferences...` (`⌘,`), `Quit` (`⌘Q`).

### 7.2 Preview Pane
- **Text / Code:** Full scrollable content with lightweight syntax highlighting, JSON pretty-print toggle if valid JSON, and plain-text view.
- **Color:** Large color preview swatch + Hex / RGB / HSL values.
- **Image:** Crisp preview scaled to pane + pixel dimensions + byte size.
- **Files:** List of copied file names/paths + total count.
- **Metadata & Hints:** `Application`, `First copy time`, `Last copy time`, `Number of copies`, plus shortcut hints (`Press ⌥P to (un)pin`, `Press ⌥⌫ to delete`, `Press ⌥S to save as snippet`).

### 7.3 Settings Tabs (Matching Maccy + Snippets)
1. **General:** Launch at login (`tauri-plugin-autostart`), `Check for updates automatically` + `Check now`, Hotkey recorders (`Open`, `Pin`, `Delete`, `Preview`, `Save Snippet`), `Search` mode (`Fuzzy`, `Exact`, `Regular expressions`, `Mixed`), `Paste automatically`, `Paste without formatting`, modifier behavior legend.
2. **Storage:** Save toggles (`Files`, `Images`, `Text`), `Size` stepper + live disk usage readout, `Sort by` dropdown (`Time of last copy`, `Time of first copy`, `Number of copies`).
3. **Appearance:** `Popup at` (`Cursor`, `Menu icon`, `Screen center`, `Active window`), `Pin to` (`Top`, `Bottom`), `Image height`, `Open Preview automatically` + `Preview delay (ms)`, `Highlight matches` (`Bold`, `Underline`, `Highlight`), toggles (`Show special symbols`, `Show menu icon` + icon selector, `Show recent copy next to menu icon`, `Show search field`, `Show title before search field`, `Show application icons`, `Show hex color swatch`, `Show footer`), Theme (`System`, `Light`, `Dark`).
4. **Ignore:** Sub-tabs for `Applications` (+ `"Ignore all applications except listed"` allowlist toggle), `Pasteboard types`, `Regular expressions`.
5. **Snippets:** List + editor for creating, tagging, setting in-popup shortcuts, previewing template variables, and importing/exporting snippets JSON.
6. **Advanced:** `Turn off` (pause capture) + CLI command reference (`clipo --pause`, `--resume`, `--ignore-next`), `Clear history on quit`, `Clear the system clipboard too`.

# Clipo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build **Clipo**, a fast, MIT-licensed, cross-platform (macOS, Windows, Linux) Clipboard History & Snippet Manager inspired by Maccy.

**Architecture:** A single Tauri v2 desktop binary with a native Rust core handling background clipboard watching, privacy filtering, SQLite + content-addressed blob storage, fuzzy/regex search, snippet variable expansion, local CLI/IPC control, tray/hotkeys, and synthetic paste. A pre-warmed hidden Svelte 5 popup window delivers sub-50ms open latency with an attached collapsible preview pane, while a lazily created settings window hosts the 5 Maccy Preferences tabs plus the Snippets manager.

**Tech Stack:** Tauri v2, Rust (`rusqlite`, `nucleo`, `regex`, `image`, `sha2`, `uuid`, `chrono`, `tray-icon`, platform clipboard/input crates), Svelte 5, TypeScript, Vite, Tailwind CSS v4, Vitest, GitHub Actions.

**Spec:** [2026-11-26-clipo-design.md](file:///Users/arafat/Documents/Products/clipo/docs/superpowers/specs/2026-11-26-clipo-design.md)

## Global Constraints

- **Target Platforms:** macOS 13+ (Apple Silicon & Intel), Windows 10/11 (x64 & ARM64), Linux (X11 full support; Wayland with explicit capability detection and graceful copy-only fallback).
- **License:** MIT License.
- **Latency & Footprint:** Pre-warmed hidden popup (`<50ms` open target); lazy settings window destroyed on close; zero Electron bloat.
- **Scope Exclusions (v1):** No cloud sync, no accounts, no telemetry, no global keystroke-logging text expansion (`;abbr`), and no global per-snippet OS-wide hotkeys (pin/snippet shortcuts are in-popup only).
- **Privacy Markers:** Skip concealed/transient entries (`org.nspasteboard.TransientType`, `org.nspasteboard.ConcealedType`, `org.nspasteboard.AutoGeneratedType` on macOS; `ExcludeClipboardContentFromMonitorProcessing`, `CanIncludeInClipboardHistory` on Windows; `x-kde-passwordManagerHint` on Linux).
- **Text & Locale:** Full UTF-8, IME search composition, and complex script shaping (Bengali, Arabic, CJK, emoji).

## Review Focus

- **Self-write & password-manager loop prevention:** Writing an item to the clipboard during copy/paste or receiving a password manager's concealed entry must never re-enter `history_items` — pinned by `test_self_write_suppression_skips_re_capture` and `test_password_manager_markers_ignored` in Task 5.
- **Invalid regex in Search or Ignore rules:** Typing incomplete/malformed regex in `Regular expressions` search mode or saving invalid regex in Ignore rules must return a safe validation/empty result without panicking — pinned by `test_invalid_regex_returns_error_gracefully` (Task 3) and `test_ignore_engine_handles_invalid_regex` (Task 5).
- **Missing or corrupt blob files on disk:** Missing files under `blobs/` during read, preview, or history pruning must degrade cleanly without aborting SQLite pruning — pinned by `test_missing_blob_file_handled_gracefully_on_read_and_prune` in Task 2.
- **Multi-format copy & plain-text paste boundary:** Rich RTF/HTML copies must retain `plain_text` + rich payloads, deduplicate by canonical `plain_text` while refreshing rich formats and `copy_count`, and strip rich formatting when plain paste is requested — pinned by `test_dedup_updates_rich_payload_and_copy_count` (Task 2) and `test_paste_payload_strips_rich_when_plain_requested` (Task 5).
- **Screen-edge popup clamping & `⌘1–⌘9` index invariance:** Popup placement near monitor edges must stay inside work area, and `⌘1–⌘9` must always map to the first 9 *unpinned* history items regardless of pinned rows or `Pin to: Bottom` — pinned by `test_quick_pick_indices_skip_pinned_and_snippets` (Task 3) and `test_clamp_popup_rect_within_work_area` (Task 7).
